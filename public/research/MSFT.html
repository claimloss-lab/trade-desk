MSFT — Microsoft Corporation

Brief สร้างโดย cron (Stock Brief Writer) · 2026-08-28 ตัวเลขหลักจาก sources/MSFT/ (10-k-fy2026, q4-2026-call) และ CNBC/Robinhood

1. Company snapshot

Microsoft ทำซอฟต์แวร์ คลาวด์ และ AI ให้ทั้งบุคคลและองค์กรทั่วโลก รายได้แบ่ง 3 กลุ่ม: Productivity & Business Processes (Microsoft 365, LinkedIn, Dynamics), Intelligent Cloud (Azure + GitHub + server products), และ More Personal Computing (Windows, Xbox, Search/Bing พร้อม Copilot) 3 กลุ่มบนสุด Azure และ Microsoft 365 กำลังเป็นตัวขับเคลื่อนหลักผ่านการขายแบบ subscription + consumption (per-seat บวก usage) มีพนักงาน ~223,000 คน ณ มิ.ย. 2026 ยุทธศาสตร์ปัจจุบันโฟกัสหนักที่ AI (OpenAI partnership + โครงสร้างพื้นฐาน datacenter ขนาดใหญ่)

2. Fundamentals signal

  • รายได้ FY2026 $331.8B +18% yoy (จาก $281.7B ใน FY2025) — เร่งตัวขึ้นตลอดปี กำไรสุทธิ $133.7B +31%, diluted EPS $17.95 +32% (รวม benefit จาก OpenAI investment gains $5B)
  • Cloud เป็นเครื่องยนต์ใหญ่: Microsoft Cloud +27% ไป $214B, Azure +41% (เกิน $100B annualized), Commercial RPO +84% ไป $678B — backlog อนาคตหนามาก
  • Margin กดดันเล็กน้อยจาก AI infra: gross margin % ลดนิดหน่อย กลุ่ม Intelligent Cloud มี cost +44% ตาม AI infrastructure (Microsoft Cloud gross margin เหลือ ~66%) — โตเร็วกว่าแต่ margin ดันลง
  • งบดุลอึด: กระแสเงินสดจากดำเนินงาน $182.9B แต่ capex ใหญ่ (Q4'26 = $41B, FY2027 คาด ~$175B) เงินสด+ระยะสั้น ~$76.8B; คืนทุน FY2026 ~$43B
  • ขยายอายุใช้ประโยชน์ datacenter จาก 15→25 ปี (มีผล FY2027) — ลดค่าเสื่อม ช่วย cushion กำไร แต่ควรดูงานนี้เป็น accounting effect ไม่ใช่ fundamentals จริง

    • Valuation snapshot (ณ 2026-08-28 ~20:30 ICT, แหล่ง CNBC/Robinhood): price ~$505, market cap ~$3.75T, P/E (trailing, GAAP FY26 EPS $17.95) ~28 / Robinhood ระบุ ~27.4, EV/EBITDA หาไม่เจอในรอบนี้, 52-week range $349.20–553.72 ตัวเลขดิบ ไม่ตีความว่าถูก/แพง

    3. Latest earnings

  • Q4 FY2026: รายได้ $90B +18% yoy, non-GAAP EPS $4.74 +23% (หลังปรับผลจาก OpenAI equity-method) — ปิดปีด้วยรายได้เต็มปี >$331B +18% (source: sources/MSFT/q4-2026-call.md)
  • แยกกลุ่ม: Productivity & Business Processes $37.8B +14% (M365 Commercial cloud +16%, M365 Copilot >30 ล้าน paid seats); Intelligent Cloud $39.3B +32% (Azure +43%); More Personal Computing $12.9B -4% (Windows OEM/Devices -7%, Xbox content/services -10%) (source: sources/MSFT/q4-2026-call.md)
  • Microsoft Cloud $59.3B +27%; Azure ซึ่ง annualized เกิน $100B +41%; GitHub Copilot 50 ล้าน users, ~1 ใน 3 ของ pull requests ใช้ AI agents (source: sources/MSFT/q4-2026-call.md)
  • Capex Q4 $41B (ราว 2 ใน 3 ไปที่ short-lived assets = CPU/GPU) บันทึกกำไร $3.2B จาก Anthropic investment คืนทุน $10.2B ในไตรมาส / $43B ทั้งปี (source: sources/MSFT/q4-2026-call.md)
  • Guidance: Q1 FY2027 รายได้ $89.85–90.95B (+16–17%); ทั้งปี FY2027 คาดรายได้+กำไรดำเนินงานโต double-digit, capex ~$175B, operating margin ลด <1pt, อัตราภาษี ~20%. Headwind: M365 Commercial/Server ลด single-digit, Windows OEM/Devices ลด high-teens (source: sources/MSFT/q4-2026-call.md; ตัวเลขเต็มใน sources/MSFT/10-k-fy2026.md)

    • 4. Bull case / Bear case

    Bull:

  • Azure +41% และ Commercial RPO +84% ไป $678B — คำสั่งซื้อ/backlog สะสมมาก หนุนการรับรู้รายได้หลายปีข้างหน้า
  • เปลี่ยนเป็น per-seat+consumption pricing (M365 Copilot, GitHub Copilot usage-based, Dynamics usage) — เปิด upside ARPU จากจำนวนผู้ใช้ที่ขยายตัว
  • ตัวเลข adoption โตเร็ว: Copilot 30M+ seats, GitHub Copilot 50M users, NHS/KPMG/HSBC/EY เลือกใช้ — พนัน AI เริ่มมี traction ที่แปลงเป็นรายได้แล้ว

    • Bear:

  • capex ก้อนใหญ่ (FY2027 ~$175B) มาก่อนรายได้ — ถ้า demand AI ไม่มาเท่าที่สร้าง capacity margin จะถูกโขกและมีเสี่ยง impairment (บริษัทเองยอมรับใน 10-K ว่า demand ยากจะคาดเดา)
  • พึ่งพา OpenAI partnership มาก (ทั้งฐานรายได้/กำไร และซัพพลาย AI) + คดี IRS ต้องการเงินเพิ่ม $28.9B (transfer pricing, ปี 2004–2013) ยังไม่จบ
  • AI กลายเป็น commodity/ถูกกดราคา หรือลูกค้าย้ายไป platform คู่แข่ง/open-source — กดดัน pricing และอัตรากำไร cloud

    • 5. Kill conditions

  • Azure เอง (ไม่นับรวมผล AI hype) หยุดเร่งโตต่ำ และ/หรือ Microsoft Cloud gross margin ร่วงต่อเนื่องหลายไตรมาสจาก AI infra โดยรายได้ไม่ตาม
  • ตัวเลข consumption/adoption (Copilot seats, GitHub, Foundry) ชะลอหรือหดจากจุดสูงสุด — สัญญาณว่า upside per-seat ไม่เกิดจริง
  • คดี IRS/ภาษี $28.9B ตกผลึก worse กว่าประมาณการ และกระทบกระแสเงินสด/หนี้
  • OpenAI relationship เสียหาย (โครงสร้างรายได้/กำไร และความสามารถทางเทคนิค) — thesis AI หลักของ MSFT พิงจุดนี้

    • 6. What to ask before owning it

  • capex ~$175B/ปี เทียบรายได้ปัจจุบัน ตัวเลขนี้อีกกี่ปีถึงจะคืนทุนถ้า AI demand โตช้ากว่าที่ตั้งไว้?
  • Azure +41% ส่วนไหนเป็นจริง consumption เทียบกับ 1-time/deal ที่ banks ไว้ และ backlog RPO ใหญ่ขนาดนี้จะรับรู้จริงไหม?
  • ต้องพึ่ง OpenAI ระดับอะไร — ถ้า OpenAI มุ่งไปพึ่ง infrastructure ของเจ้าแรก ๆ เอง MSFT เสียอะไรบ้าง?
  • คดียู IRS $28.9B และ regulation/Tax ระหว่างประเทศกระทบ margin ระยะยาวแค่ไหน?
  • เมื่อ AI แพร่หลายขึ้น ราคา inference/บริการจะถูกกดดันเป็น commodity จนกำไร cloud ลดลงไหม?

1. Company snapshot

Penguin Solutions (เดิมชื่อ SMART Global Holdings) สร้าง ติดตั้ง และจัดการโซลูชัน enterprise/rechenzentrum — 3 ส่วนธุรกิจ: Advanced Computing (ระบบ AI/technical computing, แพลตฟอร์ม OriginAI สำหรับ deploy GPU ที่ scale), Integrated Memory (โมดูลหน่วยความจำสำหรับ data center) และ Optimized LED (เดิม Cree LED) ขายทั้ง hardware + software + service ให้ enterprise, sovereign และ cloud — กำลังโฟกัสหนักไปที่ "AI factory" / GPU infrastructure มากกว่าแค่ขายชิป

    • 4. Bull case / Bear case

  • Bull: AI/GPU infrastructure demand จริง — "AI factory platform" ให้บริการ end-to-end (deploy + manage GPU) สำหรับลูกค้าที่ไม่มี hyperscaler capacity; backlog/guidance ขยับขึ้น + forward P/E ค่อนข้างต่ำ (~15.6) ถ้า EPS โตตาม ~30%
  • Bull: มี 3 segment กระจาย (Advanced Computing + Memory + LED) ลดพึ่งธีมเดียว; memory pricing ดีช่วย margin
  • Bear: ระดม convertible 0% จำนวนมาก (รวม ~$1.4B) → dilution + หนี้/แปลงหนี้กด EPS; ฐานลูกค้า AI infra อาจ lumpy/cyclical ตาม capex
  • Bear: ราคา 52wk $16–$90 ผันผวนสูง (beta 2.87) และ Barclays สงสัย valuation; business ยังพึ่ง memory + LED (segments แบบ commodity/cyclical) ไม่ใช่ pure software ที่ recurring สูง

    • 5. Kill conditions

  • ลบ position หรือ thesis ถ้า: Guidance/backlog ของ AI infrastructure ถดถอย (FI27 ~30% ไม่เกิดจริง) — valuation สวนกลับแรง
  • ถ้า dilution จาก convertible หนา กดกำไรต่อหุ้นจน EPS growth ไม่สะท้อนรายได้ที่โต — ระวัง "รายได้โต แต่ EPS แทบไม่ขึ้น"
  • ถ้า memory/GPU infrastructure cycle เปลี่ยนทิศ (ราคา memory ยุบ / AI capex ชะลอ) — หุ้น leveraged สูงในธีม capex ลงก่อนราคาหลายไตรมาส อย่าถือต่อโดยไม่มีตัวเลขใหม่หนุน

    • 6. What to ask before owning it

  • ส่วน Advanced Computing + Memory ที่โตแรง มีสัญญา/backlog ยาวแค่ไหน หรือพึ่งหนึ่งรายใหญ่?
  • Convertible notes ~$1.4B จะเจือจางกำไรต่อหุ้นเท่าไรเมื่อถูกแปลง และ refinance ลดต้นทุนจริงไหม?
  • ทําไม forward P/E ต่ำ (เพราะ EPS คาดโตมาก) — ความมั่นใจในแบบจำลองกำไร FY27 ~30% แค่ไหน?
  • ส่วน LED (Cree) กับ memory ที่เป็น cyclical มีผลต่อ EPS อย่างไรถ้า cycle พลิก?
  • รายได้ "services" recurring แค่ไหน เทียบกับ project-based ที่ lumpy?

AMZN — Thesis Update (2026-11-01)

เหตุผลที่อัปเดต: Amazon รายงาน Q3 FY2026 วันที่ 29 ต.ค. และยื่น 10-Q วันที่ 30 ต.ค.; ข้อมูลใหม่สำคัญคือเงินลงทุน OpenAI Series C รวม $50B และแนวโน้ม cash capex ปี 2027 ที่จะเพิ่มขึ้นมาก ซึ่งยังไม่อยู่ใน thesis ก่อนหน้านี้. (แหล่ง: SEC Q3 release; SEC 10-Q)

Fact: Q3 รายได้และ AWS โต แต่ FCF ติดลบ; 10-Q ระบุเงินลงทุน OpenAI $50B เป็น equity investment ไม่ใช่ capex.

Interpretation: AWS เป็นช่องทางเก็บรายได้จาก cloud/AI แต่การเติบโตของการใช้งาน Bedrock ยังไม่แสดงรายได้ AI แยก และภาระลงทุนทำให้การแปลงกำไรเป็นเงินสดอ่อนลง.

Judgment: หลักฐานใหม่เพิ่มทั้งโอกาสด้าน AWS/AI และความเสี่ยงจากเงินทุนที่ผูกกับ AI โดยตรงและ infrastructure capex; ต้องติดตามผลตอบแทน/FCF แยกกัน ไม่รวมรายการลงทุนหุ้นเข้ากับ capex.

1. Company snapshot

Amazon ดำเนินธุรกิจ e-commerce, marketplace, โฆษณา, Prime และ cloud computing ผ่าน AWS. ผู้ซื้อมีทั้งผู้บริโภค/ผู้ขายบนร้านค้าออนไลน์และองค์กรที่ใช้ compute, storage, data และบริการ AI บน AWS. AWS เป็นสัดส่วนรายได้ต่ำกว่าร้านค้า แต่เป็นแหล่งกำไรจากการดำเนินงานที่สำคัญ. คำถามหลักคือการลงทุนใน AWS/AI และ fulfillment จะสร้างกระแสเงินสดที่คุ้มกับเงินทุนที่ผูกไว้หรือไม่. (แหล่ง: sources/AMZN/10-k-fy2025.md; sources/AMZN/q3-2026-earnings-release.md)

    • 4. Bull case / Bear case

    Bull case

  • AWS โตเร็วและสร้างกำไรจาก cloud; ความต้องการ Bedrock/AgentCore อาจต่อยอดรายได้ AWS หากการใช้งานแปลงเป็นการใช้ capacity และรายได้ที่เก็บเงินจริง. (แหล่ง: sources/AMZN/q3-2026-earnings-release.md)
  • เครือข่าย marketplace, Prime, fulfillment และโฆษณาช่วยให้บริษัทมีหลายช่องทาง monetization จากลูกค้าและผู้ขาย. (แหล่ง: sources/AMZN/10-k-fy2025.md)

    • Bear case

  • FCF ติดลบขณะ capex สูงและบริษัทคาดเพิ่มการลงทุนปี 2027; หาก capacity สร้างรายได้/ผลตอบแทนช้า ค่าเสื่อมและต้นทุนเงินทุนอาจกด FCF ต่อเนื่อง. (แหล่ง: sources/AMZN/q3-2026-earnings-release.md; sources/AMZN/10-q-q3-2026.md)
  • เงินลงทุน OpenAI $50B เป็นการลงทุนหุ้นในบริษัทเอกชนที่มีการประเมินมูลค่า Level 3; มูลค่าที่รับรู้ในอนาคตมีความไม่แน่นอนและไม่ใช่รายได้จาก AWS. (แหล่ง: sources/AMZN/10-q-q3-2026.md)
  • AWS เผชิญการแข่งขัน cloud/AI และการใช้งาน AI ที่เพิ่มขึ้นยังไม่เปิดเผยกำไรต่อ workload หรือรายได้ AI แยก. (แหล่ง: sources/AMZN/10-k-fy2025.md; sources/AMZN/q3-2026-earnings-release.md)

    • 5. Kill conditions

  • AWS โตชะลอหรือ margin อ่อนลงหลายไตรมาส ขณะที่ capex/ค่าเสื่อมยังเร่ง และ FCF ไม่ฟื้นตาม capacity ที่ลงทุนไป. (แหล่ง: sources/AMZN/q3-2026-earnings-release.md; sources/AMZN/10-q-q3-2026.md)
  • เงินลงทุน/มูลค่าหุ้นเอกชนสร้างผลขาดทุนหรือความผันผวนที่มีนัย ขณะที่กำไรจากการดำเนินงานไม่รองรับภาระลงทุนและภาระหนี้/lease. (แหล่ง: sources/AMZN/10-k-fy2025.md; sources/AMZN/10-q-q3-2026.md)
  • การเติบโตของ Bedrock/AgentCore ไม่แปลงเป็นการใช้ AWS ที่สร้างรายได้และกำไรเพิ่ม โดยบริษัทเดินหน้าขยายต้นทุน infrastructure ต่อ. (แหล่ง: sources/AMZN/q3-2026-earnings-release.md; sources/AMZN/10-q-q3-2026.md)

    • 6. What to ask before owning it

    1. AWS capacity ที่สร้างขึ้นถูกใช้งานและสร้างกำไรจากการดำเนินงานได้เร็วเพียงใด เมื่อเทียบกับ cash capex และค่าเสื่อม?

    2. เงินลงทุน OpenAI มีโอกาสรับรู้มูลค่าและความเสี่ยง downside อย่างไร แยกจากรายได้และ economics ของ AWS?

    3. FCF จะกลับมาเป็นบวกเมื่อใด หาก cash capex เพิ่มขึ้นต่อในปี 2027?

    4. Bedrock/AgentCore สร้างรายได้หรือ margin แยกได้หรือยัง หรือมีเพียงตัวชี้วัดการใช้งาน?
